# 🎮 Free Fire UID Checker

A clean, responsive web application that allows users to look up comprehensive player statistics, rank info, guild details, and account creation history for **Free Fire** simply by entering a player's UID.

## ✨ Features

- **Player Overview:** Displays player name, UID, region, account creation date, and total likes.
- **Account & XP Info:** Track player level, EXP, and credit score[cite: 1].
- **Rank Information:** Detailed breakdown of Battle Royale (BR) and Clash Squad (CS) ranks, points, and max achievements[cite: 1].
- **Guild Details:** View guild name, UID, level, member count, and capacity[cite: 1].
- **Guild Leader Profile:** Check the guild leader's name, UID, level, and region[cite: 1].
- **Modern UI:** Designed with a sleek, dark-themed dashboard layout optimized for visibility[cite: 1].
